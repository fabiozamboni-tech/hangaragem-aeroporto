# Ativos visuais da Vespair

Esta pasta reúne os arquivos de marca e as imagens que compõem a versão publicada do site institucional.

| Arquivo | Aplicação no site |
| --- | --- |
| `brand/vespair-logo-oficial.svg` | Logotipo transparente exibido no cabeçalho, rodapé e favicon. |
| `images/vespair-hero.jpg` | Imagem principal do hero. |
| `images/vespair-aerodromo.jpg` | Imagem da seção de aeródromo e localização. |
| `images/vespair-lounge.jpg` | Imagem da seção de lounge e hospitalidade. |
| `images/vespair-asa.jpg` | Imagem de detalhe de asa na seção de conveniências. |

Os arquivos de mídia ficam disponíveis aqui para backup, edição e futuras atualizações do projeto. A aplicação publicada utiliza endereços de armazenamento próprios para otimizar a entrega dos arquivos no ambiente de produção.
